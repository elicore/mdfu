# Docs moved

The documentation is now an [Astro Starlight](https://starlight.astro.build/) site.

- Site source: [`website/`](../website) (`website/src/content/docs/`)
- Live site: <https://elicore.github.io/mdfu/>

The Markdown files that used to live here were migrated into the site and
removed to keep a single source of truth. See `website/README.md` for how to
author and build the docs.
