## What is mdfu?

**mdfu** is a fast, single static Go binary for fuzzy-finding Markdown notes — by body free text, frontmatter values as free text, and attribute qualifiers. It understands OKF v0.1/v0.2 and Portent/Tolaria frontmatter through one unified normalized model.

**Why mdfu?**

- One box: bare words fuzzy-match, `key:value` hard-filters, AND-combined.
- Two modes: interactive TUI picker by default, pipeable `--filter` mode (fzf-compatible).
- No daemon, no persistent index, no `cgo` by default.

```
scan → parse → query → search → output/tui
```

## Quickstart

Requires Go 1.25+.

```sh
go install github.com/elicore/mdfu/cmd/mdfu@latest
# or
git clone https://github.com/elicore/mdfu && cd mdfu && go build -o mdfu ./cmd/mdfu
```

Run it inside your notes folder — the root defaults to `.`:

```sh
cd testdata
mdfu
mdfu --filter "type:Task"
mdfu --filter "status:Draft"
```

Three filter examples to try first:

```sh
mdfu --filter "type:Task"       # → portent-task.md
mdfu --filter "tag:launch"      # → portent-task.md
mdfu --filter "author:bob"      # → generic.md (custom frontmatter)
```
