# mdfu docs (website/)

Astro Starlight site for `mdfu`, published as a GitHub Pages project site:

- URL: https://elicore.github.io/mdfu
- Base: `/mdfu/`

## Prerequisites

- Node.js 22 (see `.node-version`)
- npm

## Run

```sh
npm ci
npm run dev
```

Open the printed local URL (typically http://localhost:4321/mdfu/).

## Build / preview

```sh
npm ci
npm run build
npm run preview
```

Build output goes to `dist/`.
